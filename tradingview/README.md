# 期間 陽線/陰線 出来高差(大口検証)

TradingView用インジケーター。チャート上で期間を指定すると、その期間の
**陽線の出来高合計 − 陰線の出来高合計** を「+◯万株 / -◯万株」で表示する。

ファイル: `updown-volume-range.pine`(Pine Script v6)

## 導入

1. TradingView下部の「Pineエディタ」を開く
2. `updown-volume-range.pine` の中身を全部貼り付けて「保存」→「チャートに追加」
3. 「開始」「終了」を聞かれるので、チャート上を2回クリック

## 期間の変え方

- 左上のインジケーター名をクリック → 縦線が2本出る → 横にドラッグ
- 設定(歯車)の「期間」で日付を直接入力してもよい
- 縦線が乗っている足も集計に含む。開始と終了が逆でも動く

## 表示される内容

| 項目        | 中身                                         |
| ----------- | -------------------------------------------- |
| 陽線出来高  | 終値 > 始値 の足の出来高合計と本数           |
| 陰線出来高  | 終値 < 始値 の足の出来高合計と本数           |
| 十字線      | 終値 = 始値 の足(初期設定では差引に含めない) |
| 差引(陽−陰) | プラス = 陽線側が多い / マイナス = 陰線側    |
| 陽÷陰       | 陽線出来高 ÷ 陰線出来高(1倍超で陽線側優勢)   |
| 期間騰落率  | 期間最初の始値 → 期間最後の終値              |

設定で変えられるもの: 十字線の扱い(前の足の終値と比べて振り分け)、
単位(万株 / 株 / 自動で億株まで)、色、表の位置、文字サイズ。

## 読み方の注意

- 出来高は約定数なので、本来「買い」と「売り」は常に同数。
  陽線の出来高を買い優勢と**みなす**近似であって、大口の売買そのものではない
- 大口の買い集めは「下げ(陰線)で拾う」形でも起きる。
  差引がマイナスでも株価が下がらず出来高が膨らむ期間は、吸収の可能性がある
- 日足だと1日の出来高を丸ごと陽線/陰線のどちらかに入れる。
  精度を上げたいときは同じ期間を1時間足・5分足に切り替えて比べる
- 大口の保有の確定情報は大量保有報告書(EDINET、5%超)で確認する
